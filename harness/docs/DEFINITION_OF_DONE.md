# Definition of Done

작업은 다음 조건을 모두 만족해야 완료로 간주합니다.

- 요구사항과 영향 범위가 계획 문서에 기록됨
- 소스 변경이 계획 범위를 벗어나지 않음
- 관련 테스트와 빌드가 통과함
- `git diff --check`가 통과함
- 비밀정보·대용량 파일·생성 산출물이 커밋 대상에서 제외됨
- 검증 결과가 `VERIFICATION.md` 또는 프로젝트 문서에 기록됨
- 커밋 메시지가 변경 목적을 설명함
- 사용자가 push를 요청했거나 프로젝트 자동화 정책이 허용할 때만 원격 push 완료

검증 실패, 인증 오류, 충돌, 파괴적 작업이 필요하면 완료 처리하지 않고 중단합니다.
