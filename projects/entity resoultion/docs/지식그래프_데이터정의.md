# LCI 물질명 매칭 지식 그래프 데이터 정의

## 기준 JSON 파일

- 운영 데이터: `public/물질개념_사전_G램프_L미러_v2.json`
- LCI 참조 DB 원천: `src/data/ref_db_name.json`
- 신규 등록 샘플: `docs/지식그래프_샘플.json`

운영 JSON의 최상위 구조는 다음과 같습니다.

```json
{ "nodes": [], "edges": [] }
```

각 항목은 `node_id`, `node_type`, `name`, `props`를 사용하고, 각 관계는 `edge_id`, `edge_type`, `cardinality`, `from`, `to`, `props`를 사용합니다.

## 엑셀 정리 기준

워크북을 만들 때는 아래 네 개 시트로 구성합니다.

| 시트명 | 주요 열 | 용도 |
| --- | --- | --- |
| 항목 | node_id, node_type, 항목명, 설명, 속성(JSON) | 제품유형부터 라벨·표기형태까지 모든 항목 관리 |
| 관계 | edge_id, edge_type, cardinality, from, to, 설명, 속성(JSON) | 항목 간 방향성과 관계유형 관리 |
| 코드 | 항목유형, 코드명, 코드값, 설명, 예시 | 약어·식별자·규격코드·라벨유형·표기변형·한정자 등 관리 |
| ref_id 매핑 | 물질개념 ID, 물질명, 참조물질명, LCI DB명, ref_id, 매핑 우선순위 | LCI DB 참조 매핑 검토 및 관리 |

## 항목 유형

| node_type | 한글명 | 설명 |
| --- | --- | --- |
| product_type | 제품유형 | 자동차 부품과 같은 최상위 제품군 |
| part | 파트 | G램프, L미러 등 제품 파트 |
| component | 구성품 | 하우징, 렌즈 등 파트를 구성하는 항목 |
| concept | 물질개념 | 동일성을 갖는 표준 물질 개념 |
| domain | 도메인 | 플라스틱, 금속 등 분류 도메인 |
| process | 공정 | 사출성형, 조립 등 제조 공정 |
| reference_material | 참조물질 | LCI DB의 환경영향 데이터 기준 물질 |
| label | 라벨 | 선호명, 약어, 관용어, 상품명, 번역 등 명칭 표현 |
| surface_form | 표기형태 | 대소문자·공백·하이픈·첨자·OCR 오류 등 표기 변형 |
| identifier | 식별자 | CAS, EC, UN, 내부코드 등 식별정보 |
| qualifier | 한정자 | 농도, 순도, 등급, 염·수화물, 물리형태 등 조건 |
| spec_code | 규격코드 | KS, JIS, ASTM, EN, ISO, IMDS 등 규격 체계 코드 |

`label`, `surface_form`은 그래프 캔버스에서는 과밀 방지를 위해 숨기지만, 항목 상세 및 JSON에는 포함합니다.

## 주요 관계 유형

| edge_type | 한글명 | from → to | 설명 |
| --- | --- | --- | --- |
| HAS_PART | 파트 포함 | 제품유형 → 파트 | 제품유형에 속한 파트 |
| HAS_COMPONENT | 구성품 포함 | 파트 → 구성품 | 파트를 구성하는 항목 |
| MADE_OF | 물질 구성 | 구성품/파트 → 물질개념 | 사용 물질 |
| BRIDGES_TO | 참조물질명 | 물질개념 → 참조물질 | LCI DB 참조 데이터 매핑 |
| HAS_LABEL | 라벨 | 물질개념 → 라벨 | 명칭 표현 |
| HAS_SURFACE_FORM | 표기형태 | 라벨 → 표기형태 | 검색용 표기 변형 |
| HAS_IDENTIFIER | 식별자 | 물질개념 → 식별자 | CAS 등 식별정보 |
| HAS_QUALIFIER | 한정자 | 물질개념 → 한정자 | 농도·형태 등의 조건 |
| HAS_SPEC_CODE | 규격코드 | 물질개념 → 규격코드 | 규격·재질 코드 |
| BROADER_THAN | 상위어 | 상위 물질개념 → 하위 물질개념 | 계층 관계 |
| USED_IN_PROCESS | 공정명 | 파트/구성품 → 공정 | 적용 제조공정 |

## ref_id 매핑 규칙

1. `BRIDGES_TO`로 물질개념과 참조물질을 연결합니다.
2. `reference_material.props.ref_id`와 `lci_db_name`을 사용합니다.
3. 참조 이름 후보 중 `production`을 1순위, `market for`를 2순위로 선택합니다.
4. `treatment of` 후보는 매핑에서 제외합니다.
5. 매핑 근거는 `lci_mapping_priority`에 `production 우선`, `market for 차선`, `매핑 후보 없음`으로 기록합니다.

## 프록시 물질 매핑

대체어는 동일 물질의 다른 이름이지만, 프록시 물질은 원 물질과 동일하지 않은 참조물질을 LCI 데이터 공백 시 임시로 사용하는 매핑입니다. 프록시는 별도 `BRIDGES_TO` 관계에 아래 속성을 기록합니다.

| 속성 | 값/설명 |
| --- | --- |
| match_type | `프록시` |
| mapping_kind | `lci_proxy` |
| same_substance | `false` |
| proxy_reason | 선정 근거 |
| conservatism_direction | 과소/과대평가 가능성 또는 검토 필요 |
| uncertainty_comment | 불확실성 설명 |
| proxy_review_required | `true` |

현재 예시로 ASA → ABS, 무방향성 전기강판 → 저합금강, 폴리아미드계 핫멜트 접착제 → 금속용 접착제 매핑이 프록시로 표시됩니다.
