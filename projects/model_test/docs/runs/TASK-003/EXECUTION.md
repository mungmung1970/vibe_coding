## 1. SOT 갱신

`docs/sot/SOT.md`가 다른 프로젝트("AIOps Console", version 0.3)를 가리키고 표준 명령이 `...` 자리표시자였다. 섹션 구조는 유지한 채 이 저장소 기준으로 채웠다.

- 프로젝트 정의와 화면 기준(참조 이미지) 명시
- Runtime 절 신설: 콘솔 서버는 표준 라이브러리만, 서빙은 `.venv-vllm`의 vLLM 0.28.0, GPU 1장 단일 서빙, 가중치 위치
- Install/Run/Test/Lint/Build 명령을 실제 동작하는 값으로 교체

버전은 0.3 → 0.2로 낮췄다. 기존 값은 다른 프로젝트의 것이라 승계하지 않고 이 저장소의 실제 진행도를 표기했다.

## 3. ThinkingCap 등록 유지

`thinkingcap-qwen3.6-27b`를 **유지**하기로 하고 근거를 `models/README.md`에 적었다. Qwen3.6 base는 3.8로 교체했지만 이 모델은 사고 과정 강화 파인튜닝이라 3.8과의 비교 대상으로서 값이 있고, 등록부 항목은 서빙과 무관하게 비용이 없다. 불필요해지면 디렉터리 삭제만으로 정리된다.

## 4. gpt-oss-120b 기동 재시도

같은 설정으로 재시도했다. 이전 실패는 flashinfer 커널(cubin) 내려받기 도중 로그가 끊기며 프로세스가 사라진 형태였고, 이번에는 커널 캐시가 채워진 상태라 그 구간을 통과했다.

| 구간 | 1차 시도 | 2차 시도 |
| --- | --- | --- |
| 가중치 로드 | 66.22GiB / 96.4초 | 66.22GiB / 41.6초 |
| torch.compile | 캐시 없음 | AOT 캐시 재사용, 0.13초 |
| flashinfer cubin | 다운로드 중 중단 | 통과 |

결과는 VERIFICATION에 기록한다.
