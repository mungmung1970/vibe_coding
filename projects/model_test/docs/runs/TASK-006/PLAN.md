# TASK-006 · PLAN — 탭 모양 정리와 채점 순위 표시

작성일: 2026-09-07
상태: 사용자 요청으로 즉시 실행 (소규모 변경)

## 범위

| # | 요구 | 방법 |
| --- | --- | --- |
| R1 | 상단 탭을 알약 모양이 아니라 **모서리만 둥근 사각형**으로 | `.tab`의 `border-radius`를 999px → 6px |
| R2 | 두 탭의 **가로 폭 동일** | `.tab`에 고정 폭 지정 |
| R3 | 답변 비교에서 **모델별 적절성 순위** 표시 | 심판 점수를 내림차순 정렬해 순위를 매기고, 답변 번호와 함께 모델명을 표시 |

제외: 채점 프롬프트 변경, 백엔드 API 변경.

## 설계

순위는 심판이 준 `score`를 기준으로 **화면에서 계산**한다. 모델이 순위를 직접 말하게 하면 점수와 어긋날 수 있고, 동점 처리도 제각각이기 때문이다. 동점은 같은 순위를 주고 다음 순위를 건너뛴다(1, 1, 3).

답변 번호(`index`)를 비교 대상 `runs` 배열과 맞춰 모델명을 함께 보여준다.

## 영향 파일

- `src/frontend/src/styles/index.css` (R1, R2)
- `src/frontend/src/components/history-view.js` (R3)
- `src/frontend/tests/unit.test.js` (순위 계산 테스트)
- `src/frontend/src/utils/format.js` (순위 계산 순수 함수)

백엔드 변경 없음.
