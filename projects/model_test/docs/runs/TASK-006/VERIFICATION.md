## 실제 채점 순위

`claude-sonnet-5`를 심판으로 모범답변과 대조한 결과가 화면에 이렇게 나온다.

```
순위 | 모델                  | 답변    | 점수
1위  | openai-gpt-5.4-mini   | 답변 2  | 95점 — 모범답변의 핵심 내용을 정확하고 간결하게 반영했다

```

순위는 심판이 준 점수를 **화면에서 내림차순 정렬해 계산**한다. 모델이 스스로 매긴 순서를 신뢰하면 점수와 어긋날 수 있고 동점 처리도 제각각이기 때문이다.

## 스크롤 구조 변경

`.workspace`를 뷰포트 높이에 고정하고(`height: calc(100vh - 44px); overflow: hidden`), 사이드바와 본문이 각자 `overflow-y: auto`로 스크롤한다. 그 결과 창 오른쪽 스크롤바는 결과 화면만 움직이고 좌측 메뉴는 제자리에 남는다. 결과 카드에 걸려 있던 자체 높이 제한(`max-height`)은 본문이 스크롤되므로 제거했다.

좁은 화면(≤900px)에서는 기존처럼 페이지 전체가 스크롤되도록 예외를 두었다.
