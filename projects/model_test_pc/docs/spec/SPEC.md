# SPEC · model_test_pc

버전: 0.1 · 2026-09-07

## 1. 목적

여러 모델의 답변을 같은 조건에서 비교한다. 모델은 **HTTP 엔드포인트 호출**로만 사용하며, 로컬 서빙·GPU·가중치를 다루지 않는다.

## 2. 기능 요구사항

### F1. 모델 등록과 선택
- F1.1 `models/<id>/model.json`에 엔드포인트를 등록하면 목록에 나타난다. 서버 재시작이 필요 없다.
- F1.2 모델 선택은 **즉시 반영**된다. 기동 대기가 없다.
- F1.3 `base_url`은 `${환경변수}` 표기를 지원한다. 값이 없으면 호출 불가로 보고 목록에서 제외한다.
- F1.4 API 키가 필요한 모델은 키 준비 여부를 화면에 표시한다.
- F1.5 모델명에 유형(LLM/VLM)을 표기하고 유형으로 거를 수 있다.

### F2. 파라미터
- F2.1 전달 가능한 파라미터는 `app/data/parameters.json` 한 곳에서 정의한다.
- F2.2 노출 기준은 모델의 **파라미터 프로필**(`vllm`/`openai`/`anthropic`)이다. 같은 OpenAI 규격이라도 vLLM 엔드포인트는 `top_k` 같은 확장 필드를 받는다.
- F2.3 모델별 `unsupported_fields`는 요청에서 제거한다.
- F2.4 서버는 값의 타입·범위·선택지를 검증하고 위반 시 422로 거부한다.

### F3. 실행
- F3.1 시스템 프롬프트와 질문을 보내 답변을 스트리밍으로 받는다.
- F3.2 사고 과정(reasoning)은 본문과 분리해 표시하고, 본문 전에는 진행 상황을 보여준다.
- F3.3 VLM 모델에 한해 이미지를 첨부할 수 있다(최대 4장). 공급자별 형식 변환은 어댑터가 담당한다.
- F3.4 엔드포인트 미도달·키 누락·공급자 거부는 각각 구분되는 오류로 알린다.

### F4. 기록과 비교
- F4.1 **저장 버튼을 눌렀을 때만** 기록에 남는다.
- F4.2 모델·검색어·기간으로 조회하고, 화면에서 숨기거나 삭제한다.
- F4.3 둘 이상을 선택해 답변과 파라미터 차이를 비교한다.
- F4.4 모범답변과 심판 모델을 지정하면 점수·순위를 계산한다. 등록된 모든 모델이 심판이 될 수 있다.

## 3. 범위 밖

- 로컬 모델 서빙, vLLM, GPU 관리
- 인증·권한
- 여러 요청 동시 실행, 부하 제어
